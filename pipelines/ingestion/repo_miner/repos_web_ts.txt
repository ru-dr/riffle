# web-ts domain (ADR 0011): JavaScript/TypeScript web ecosystem, the first
# domain to prove. Mine with:
#   python build_dataset.py --repos-file repos_web_ts.txt --only-domain web-ts \
#       --window-from 2023-07-01 --window-to 2026-07-31 --max-prs 8000
# [~N commits] counts are from the GitHub API on 2026-10-19. [monorepo] marks
# app monorepos, reported as their own subgroup. Hold out 6-8 repos for
# validation and 6-8 for test, at least one monorepo in each.
# Left out: microsoft/TypeScript (now Go), pnpm/pnpm (now Rust), nodejs/node
# (commit queue), angular/angular (own merge tooling), electron/electron
# (mostly backport bots), withastro/astro (two thirds bot PRs),
# getsentry/sentry and PostHog/posthog (few outside PRs).
